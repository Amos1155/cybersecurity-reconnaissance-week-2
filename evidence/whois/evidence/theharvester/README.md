# theHarvester Evidence

This folder contains screenshots and selected results from the theHarvester OSINT exercise performed against the assigned `microsoft.com` target.

The exercise collected publicly available information, including hostnames, IP addresses, email addresses, ASNs, and URLs.

Some data sources were unavailable because of API-key restrictions or service errors. The results should therefore be treated as collected OSINT data, not confirmed security vulnerabilities.

Only sanitized and approved evidence will be published here.
